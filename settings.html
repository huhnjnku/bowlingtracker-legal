Settings Reference

Every option in the Settings tab, top to bottom. This is the coach-mode Settings — parent mode has a stripped subset.

School System Profile

School Name

Text field. Appears on PDFs, in exports, and in your shared match snapshots. Change it and tap Save Profile Settings.

Advanced Match & Theme Setup

A collapsible section holding several sub-groups.

Brand Color Schemes

  • Primary color — used for accent buttons and highlights.
  • Secondary color — used for the secondary format badge and some UI accents.

Pick your school colors. Saved when you tap Save Profile Settings.

Enabled Tracking Match Formats

  • Show Head to Head Format — toggle. Default on. When off, the H2H option disappears from the Match Format picker in the Log Match tab.
  • Show Tournament Format — same idea for Tournament.
You must leave at least one on. If you're a league-only coach, you can disable Tournament to declutter the picker.

Squad Naming Presets

Up to six preset slots for the Add Squad menu in Log Match. Each slot has:

  • A squad name text field
  • A gender segmented picker (Boys / Girls)

Default fills:

  1. Boys Varsity
  2. Girls Varsity
  3. Boys JV
  4. Girls JV
  5. Boys Freshmen
  6. Girls Freshmen

Leaving a name blank falls back to the built-in default for that slot.

Hidden when Live Match Scoring is on. If you flip on LMS, the presets are replaced by real CoachSquad records you manage directly in the LMS section below.

Roster (Toolbar Button)

The people icon in the top-right toolbar opens the roster manager. See Managing Your Roster.

App Mode

A single toggle button showing your current mode:

  • Coach — full tracking & roster tools (currently in Coach mode)
  • Parent — stripped tracker for a bowler's pin data (currently in Parent mode)

Tap Switch to Parent or Switch to Coach to change. A confirmation dialog warns what the change entails.

Live Match Scoring

Use Live Match Scoring (main toggle)

When off, the app is fully local. When on, you get co-coach sync, parent live scoring, and (optionally) Google Sheets integration.

Turning it on for the first time shows the paywall unless you're grandfathered. Once purchased, a one-time warning appears: "Turning Live Match Scoring on mid-season can split your season stats if new squad names don't exactly match your existing history."

Turning it off doesn't cost you anything. Your existing matches stay. If you turn it back on later, your CoachSquads reappear as they were.

I create and share squads (ownership toggle)

Appears when LMS is on. Two use cases:

  • On — You're the primary coach for at least one squad and will invite co-coaches and parents.
  • Off — Another coach owns the squads and will send you an invite. You'll join squads instead of creating them.

Squads You Own

Only shown when ownership toggle is on. Lists every CoachSquad you've created.

Add Squad button opens a sheet with:

  • Squad Name text field
  • Pool selector (Boys / Girls)
  • Save button

Each squad row shows:

  • Squad name and pool pill
  • Status pills: Synced (published to iCloud), Shared (you've shared with co-coaches or parents), Sheets (Google Sheets webhook configured)
  • Publish button — pushes the squad up to iCloud. Enables sharing.
  • Share icon — opens the iCloud share sheet; copy the link for parents/co-coaches.
  • Push History button — one-shot publish of every existing match for this squad.
  • Sheets icon — Google Sheets webhook config. See Google Sheets.
  • Delete icon — removes the squad locally and publishes a tombstone to any co-coaches.

Squads You Co-Coach

Lists squads owned by someone else that you've been invited to. Same status pills as owned squads. The delete button is replaced with a Leave button — leaving unsubscribes you but doesn't delete the owner's data.

Join via URL

A dedicated button that opens a paste-URL sheet. Useful when the coach shared an invite link via text/email and iOS's tap-to-accept doesn't work (a common pre-launch TestFlight issue).

Paste the invite URL → tap Save → the squad appears in your Co-Coach list.

Debug Options (DEBUG builds only)

Lane Camera Tab (DEBUG)

Enables a hidden tab that uses your phone's camera plus computer vision to try to auto-detect ball position, pin position, and rotation on the lane. Currently in R&D and hidden from released builds — you won't see this toggle in TestFlight or App Store builds.

Parent Mode Settings

When in Parent mode, Settings is trimmed to:

  • Brand colors
  • App Mode toggle (to switch back to Coach)

Everything coach-related is hidden.
