Parent Mode

Parent mode is a stripped experience for two things:

  1. Helping the coach by tracking pin data during a match.
  2. Following your bowler's team live from anywhere (Live Match Scoring subscribers only).

To enter Parent mode from a fresh install, pick Parent on the mode selector. Existing users switch via Settings → App Mode.

The Four Parent Tabs

  1. Track — record pin telemetry for a bowler in a specific match.
  2. Live — read-only live scoreboard from subscribed squads.
  3. Statistics — pin-derived stats for players you've tracked.
  4. Settings — colors and mode toggle.

First-Time Setup: Scan a Coach Roster

Before you can track anything, you need a roster from your bowler's coach. Ask them to open Settings → Roster → tap the QR icon → show you the QR code.

  1. In Parent mode: Track tab.
  2. Tap the person icon in the top-right toolbar → Rosters.
  3. Tap Scan Coach Roster.
  4. Allow camera access if prompted.
  5. Point your camera at the coach's QR code.
  6. Preview appears showing the school, pool, version, and player list.
  7. Tap Save Roster.

The roster is stored locally on your device. It doesn't sync anywhere — it's just a lookup table so you know which player you're tracking.

Same coach, both pools? If your bowler's coach runs both boys and girls squads, they'll share two QR codes — one per pool. Scan both. Your device supports multiple rosters from multiple schools too, if you have kids at different programs.

The Track Tab

Starting a New Tracked Match

  1. Tap Start New Match (blue button).
  2. Pick the roster (which team + pool your bowler is on).
  3. Pick your bowler from the player list.
  4. Set the match date.
  5. Optionally add a squad name (helps you distinguish similar matches later).
  6. Tap Start Tracking.

Tracking During the Match

The tracked-match card opens the pin tracker canvas. Every ball you tap:

  • Tap standing pins as they're hit down.
  • Use the shortcut buttons: Strike (X), Spare (/), Clear Deck.
  • The frame auto-advances on strike or spare.
  • 10th-frame ball 3 appears automatically after a strike or spare in ball 1/2.

You can leave and return — everything is auto-saved locally.

Warning Badge

If a player is missing from your latest roster (coach renamed them, removed them, or you scanned an older QR), an orange warning triangle appears on the match card with the note: "This player isn't in your latest roster — ask the coach for a refreshed QR."

Sharing Your Pin Data Back to the Coach

Once the match is done, tap into the match → use the trailing menu to Export a parent packet. This creates a file you can AirDrop or email to the coach; they import it via the History tab.

Deleting a Tracked Match

Swipe left on the match card → tap Delete. Confirmation dialog.

The Live Tab

The Live tab shows a read-only scoreboard for any squad you're subscribed to. Requires:

  • The coach has Live Match Scoring enabled and has published the squad.
  • You've subscribed via the invite URL.

Subscribing to a Live Squad

The coach sends you an invite URL via text, email, or whatever.

  • Best case — tap the URL, iOS opens the app, and you see: "You're now subscribed to Boys Varsity. Live scores will appear here as your coach scores matches."
  • Fallback — tap doesn't work? Open the Live tab → tap Paste Share URL → paste the URL manually.

Multiple Squads

You can subscribe to several squads (varsity, JV, sibling's team). A pill bar at the top of the Live tab lets you switch between them.

What the Scoreboard Shows

  • Header — squad name, opponent name(s), tournament name (as applicable).
  • Big totals — the current team score for each side. For quad matches, all four totals shown compactly.
  • Player grid — 8 starters + 3 subs, one row each, with per-game columns.
  • Baker row — highlighted purple if any baker scores exist.
  • Opponent summary — for H2H matches, each opponent's per-bowler scores in an anonymized format ("Bowler 1: 280, 150"). Names are redacted for privacy.
Empty cells show as a dash. Games your bowler hasn't bowled yet display "—" instead of 0 — a 0 would look like they bowled a really bad game.

Empty State

If no match is currently live, you see: "No live scores have been posted today. You'll see live scores here as soon as your coach starts scoring a match."

Live Match Notifications

The first time you open the Live tab, iOS asks whether to allow notifications. Allow, and you'll get:

  • A ping when the coach starts scoring a match.
  • A ping with the final score when the match ends.
  • A ping any time any bowler on the squad hits 279 or higher.
  • A ping if the team bowls a baker game of 279 or higher.

Notifications only fire from the background. When you're actively in the app, they stay suppressed — the Live tab shows the updates instead.

Can't get notifications? Settings → Notifications → Bowling Tracker on your iPhone. Make sure Allow Notifications is on. If they still don't fire, it's likely that the coach hasn't scored any new events since you subscribed.

The Statistics Tab

Stats derived entirely from the pin data you've tracked yourself. Only shows bowlers you've personally tracked.

  • Match count
  • Completed games
  • Average (from pin telemetry, not the coach's typed scores)
  • Strike percentage
  • Spare percentage

If you haven't tracked anyone yet, you see the empty state: "No tracked players yet. Track a match in the Track tab and pin telemetry stats for that bowler will show up here."

The Parent Settings Tab

Minimal:

  • Brand color pickers (Primary/Secondary)
  • App Mode toggle to switch back to Coach
