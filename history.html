Match History

The Historical Matches tab shows every saved match sorted newest-first. It's the hub for reviewing, sharing, editing, and exporting matches.

Filtering the List

At the top, the View History picker lets you narrow the list:

  • Last 7 Days — quick recent-view.
  • Custom Range — reveals start and end date pickers.
  • School Year — dynamically populated based on the earliest match you have. Uses the standard August 1 – July 31 school-year boundary.
  • Show All — every match in the app.

Match Card Anatomy

Each match in the list shows:

  • Date (MM-dd-yyyy)
  • Squad name (e.g. Boys Varsity)
  • Format badge — H2H or Tournament in your brand colors
  • Card title — opponent name (H2H) or tournament name (Tournament)

Tap any card to open an action sheet with per-match options.

Per-Match Action Sheet

Tap a match card and you'll see these buttons:

Summary

Opens the Detailed History Card for that match. Shows the full breakdown:

  • Match metadata (squad, opponent, date, location, oil pattern)
  • Per-player game scores with high game highlighted
  • Baker set scores
  • Final team totals and W/L result
  • An Edit button at the top (routes to Log Match in historical edit mode)
  • An amber Score Mismatch banner if any player's typed score differs from their pin-derived total (see below)

Share to Coach

Exports the match as a .bowlingmatch file (CSV format under the hood). Opens the iOS share sheet — AirDrop, Mail, Messages, Files, etc.

The receiving coach's app will detect the file on tap and offer to import it. See Sharing & Export.

Export JSON (Single Match)

Exports a .bowlingmatchjson file. This preserves everything CSV can't — tri/quad opponents, full pin telemetry, oil pattern details, baker attribution. Preferred format for round-trip backup.

Export Season JSON

Exports a .bowlingseasonjson containing multiple matches, the roster snapshot, and all telemetry. Useful for archiving a whole season or moving data between devices.

Import Parent Data

Opens the parent-packet importer. If a parent tracked pin data for one of your bowlers during this match, they can export it as a parent packet and send it to you — this button imports that data into the match.

Export PDF Match Overview

Opens the PDF options sheet:

  • Include opponent per-player scores — off by default. When off, the opponent block is anonymized (bowler 1, bowler 2, etc.).
  • Generate — produces the PDF and opens a Mail composer with it attached.

The PDF is the coach-facing match report — one page (or two for quad matches) with squad totals, per-bowler stats, and the baker set.

Delete

Confirmation dialog, then removes the match locally. If Live Match Scoring is on and the squad was shared, a "tombstone" is published to iCloud so co-coaches also see the deletion.

Swipe-to-Delete

Swipe left on any match card in the list for a quicker delete. Same confirmation dialog.

Score Mismatch Banner

If any player's typed score doesn't match the score computed from their pin telemetry for the same game, the detailed history card shows an amber banner listing the specific mismatches.

Which score "wins"? The scoresheet total is always authoritative. The banner just flags the discrepancy so you can review. This is intentional — pin telemetry can be incomplete or entered mid-frame, but the final total is what counts.

Importing Matches

The Import button in the toolbar (top-right) opens a file picker. Supported formats:

  • .bowlingmatch — single-match AirDrop from another coach
  • .bowlingmatchjson — single-match JSON
  • .bowlingseasonjson — bulk season import
  • .csv / .txt — legacy 216-column coach CSV format

Imports match on UUID — importing a match that already exists locally will overwrite it.

Auto-Backfill (Live Match Scoring)

When you first publish a squad to iCloud (Live Match Scoring), the app offers to backfill the current season's matches. Say yes and all your existing matches for that squad get pushed up so co-coaches can see historical data too.

You can also manually push a broader window later via the Push History button in Settings. See Live Match Scoring.
