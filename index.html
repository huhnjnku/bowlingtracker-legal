Bowling Tracker — User Guide

Everything a coach or parent needs to know about the app, from first launch to live match scoring.

Bowling Tracker is a scoring, roster, and stats app for high school bowling programs. Coaches score matches, track pin telemetry, and share live scores with parents. Parents can follow live scores and help by tracking pin data for their bowler. All core features are free — an optional in-app purchase unlocks the Live Match Scoring toolkit.

What's free and what's premium

All core features are free — full scoring, roster, history, statistics, PDF/CSV/JSON export, QR roster sharing, AirDrop match sharing, and parent-mode tracking.

The only paid feature is Live Match Scoring, a one-time $4.99 in-app purchase that unlocks:

  • Coach-to-coach match sync via iCloud (e.g. Varsity and JV on separate devices, one shared roster)
  • Live score sharing with parents and staff
  • Push notifications for match start, match end, and 279+ high games
  • Optional live push to a Google Sheet for broadcasts and public scoreboards
Grandfather rule: If you already had a squad set up before the paid version launched, you keep Live Match Scoring for free — the app checks on first launch and grants access automatically.

Two modes, one app

The app runs in either Coach mode (default) or Parent mode. You pick on first launch and can switch any time in Settings.

  • Coach mode — full scoring, roster management, history, statistics, and (optional) Live Match Scoring. Four tabs: Log Match, Historical Matches, Statistics, Settings.
  • Parent mode — a stripped experience for parents helping with pin tracking or following live scores. Four tabs: Track, Live, Statistics, Settings.
