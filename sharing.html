Every way you can get data in or out of the app.

Sharing a Match (Coach → Coach)

Two paths, depending on what your receiver has:

AirDrop the .bowlingmatch File

  1. Historical Matches tab → tap the match → Share to Coach.
  2. iOS share sheet opens.
  3. Pick the receiving coach's device via AirDrop, or send via Mail/Messages.
  4. They tap the file → the app detects the extension → they import via the preview sheet.

Live Match Scoring Co-Coach Invite

If you both have LMS and you're on the same squad, no file transfer needed — matches sync automatically. See Live Match Scoring.

Exporting to JSON

Single Match

  1. Historical Matches → tap a match → Export JSON (Single Match).
  2. iOS share sheet → save to Files, AirDrop, Mail, etc.

Season Bulk

  1. Historical Matches → tap any match → Export Season JSON.
  2. The export uses your current History filter as the scope. Filter to "Show All" first if you want everything.
  3. The file includes: match records, roster snapshot, and pin telemetry.

Import a JSON file via the toolbar Import button in Historical Matches. It auto-detects the format from the extension.

Exporting a PDF Match Overview

  1. Historical Matches → tap a match → Export PDF Match Overview.
  2. PDF options sheet appears:
    • Include opponent per-player scores — off by default. When off, opponent bowlers appear as "Bowler 1", "Bowler 2" etc. for privacy.
  3. Tap Generate.
  4. A Mail composer opens with the PDF attached. Send to parents, athletic director, whoever.

Roster QR Sharing (Coach → Parent)

  1. Settings → tap the Roster people icon in the toolbar.
  2. Tap the QR icon at the top of the roster manager.
  3. Show the QR code on your screen.
  4. Parents scan it with their copy of the app (Parent mode → Rosters → Scan Coach Roster).
The QR encodes: school name, gender pool, roster version, and every active player + grad year. Nothing sensitive — no birth dates, no addresses. Just what parents need to identify their bowler.

Bumping the Roster Version

Every roster edit (add, edit, soft-delete, reactivate) automatically bumps the roster version. Parents scanning an older QR see a warning that their tracked players may be stale.

You can manually bump the version too from the QR share screen — useful if you want to force parents to rescan.

Parent Packet (Parent → Coach)

When a parent tracks pin data for your bowler, they can send the raw data back to you.

Parent Side

  1. Parent taps their tracked match → export → picks the parent packet format.
  2. AirDrop, Mail, or Messages the file to you.

Coach Side

  1. Historical Matches → tap the corresponding match → Import Parent Data.
  2. Pick the file the parent sent.
  3. Preview screen shows each imported row with:
    • A reassignment picker (in case the parent tracked a different player ID)
    • An action picker (Import or Skip)
    • A status indicator: Matches roster, Exists in roster but not on this match, Not in roster
  4. Tap Apply to merge the selected rows into the match's pin telemetry.

Importing Matches

Historical Matches → toolbar Import button. Supported extensions:

  • .bowlingmatch
  • .bowlingmatchjson
  • .bowlingseasonjson
  • .csv / .txt

Matches with the same UUID overwrite existing local copies (safe re-import).

Google Sheets Export

See Google Sheets Integration for the live-push flow. There's no one-shot "export to Sheets" button — the integration is designed for live match streaming rather than bulk export.

Need Sheets-flavored bulk export? Use CSV export → open in Google Sheets → File → Import. This works for all match data (single-opponent only).

CSV Export Limitations

The 216-column CSV format was defined before tri/quad match support. When you export a filter that includes tri/quad matches:

Tri/quad matches are silently excluded from CSV export. An alert warns you: "The CSV format is single-opponent only. N of M matches (Tri/Quad) will be excluded from this export."

Use JSON exports for the full data.
