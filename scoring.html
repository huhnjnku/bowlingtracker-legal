Scoring a Match

The Log Match tab is where you actually score. This walkthrough covers the full flow: creating a squad, picking a format, entering scores, and saving.

Adding a Squad Workspace

Every match belongs to a squad — a named team + pool combination (e.g. Boys Varsity). Tap Add Squad to open a new workspace.

  • Live Match Scoring off — you pick from up to six preset slots (Boys Varsity, Girls JV, etc.) that you configured in Settings.
  • Live Match Scoring on — you pick from your published CoachSquad records (see Live Match Scoring).

You can open multiple squad workspaces at once — say, Varsity and JV bowling the same night — and swipe between them via the chip row at the top.

Picking a Match Format

Each squad workspace has a format picker (only shown if you haven't disabled formats in Settings):

FormatUse forOpponent scoring
Head to Head (H2H) Single dual meet, tri-match, or quad-match Yes — you score both teams
Tournament Baker + individual formats at a tournament event Only your team
Open Tracking Practice sessions or unofficial scoring No — this is a self-only format

H2H Sub-Format (Single / Tri / Quad)

When you pick H2H, a second picker appears:

  • Single — 1 opponent, the classic dual meet.
  • Tri-Match — 2 opponents, all three teams on the same lanes.
  • Quad-Match — 3 opponents.

Tri and quad matches unlock additional opponent name fields and generate separate scorecards per opponent.

Configuring the Match

Squad Name

Editable text field. In Live Match Scoring mode this is locked once the workspace is created (renaming would break the sync link), except for Open Tracking where you can rename freely.

Roster Pool

Boys or Girls. Determines which players appear in the roster picker below. In Live Match Scoring mode this is also locked for H2H and Tournament, but editable for Open Tracking.

Opponent Name(s)

Type-ahead autocomplete pulls suggestions from your match history. For tri/quad, additional opponent fields appear ("Opponent 2", "Opponent 3").

Tournament Name

Only for Tournament format. Optional; autocompletes from history.

League Match Toggle

H2H only. Marks the match as league play for filtering purposes in Statistics.

Location (Alley/Lane)

Free-text; autocompletes from history. Used in PDFs and exports.

Oil Pattern

House Pattern or Sport Pattern. If Sport, a text field appears for the specific pattern name (e.g. Silk Road). This shows up in Statistics under "condition splits."

The Scorecard Grid

Below the config, you get one big grid per team. For H2H you switch between your team and each opponent via segmented tabs at the top of the scorecard section.

Rows

  • Starters 1-8 — always visible
  • Subs 1-3 — for late substitutions
  • Baker row — for baker-format games (usually 3-6 baker games per match)

Columns

  • Player — roster picker. Only shows players in the current pool, minus anyone already assigned in another open squad workspace (to prevent double-booking).
  • Game 1 through Game 6 — score fields, 0-300. Blank = didn't bowl this game.
  • Pin Track — button that opens the live pin-tracking canvas for that player/game combination.
Baker vs. individual pins. Pin telemetry for individual games and baker games are tracked separately. Baker pins never count toward per-player individual averages — see Statistics.

Live Pin Tracking

Tap the Pin Track button next to any game to open the pin canvas. You tap pins to mark them as knocked down or standing, and the scorecard subtotal updates live.

  • Auto-strike default — the first ball defaults to a strike; tap pins that are still standing to correct.
  • Auto-advance — shortcut buttons (Strike / Spare / Clear Deck) auto-advance to the next frame.
  • 10th-frame ball 3 — auto-shown when frame 10 ball 1 is a strike or ball 2 is a spare.
  • Clear game data — a toolbar button lets you wipe pin data for the current game if you need to start over.
Pin telemetry never overwrites your scoresheet totals. If your typed score and your pin-derived score disagree, the app shows an amber banner on the match history card so you can review — but the scoresheet always wins.

Multiple Squads at Once

When two or more workspaces are open, a blue banner may appear at the top of the Additional Configurations drawer: Match Format Sync Manager. It's shown when squads have mismatched Format, Opponent, Alley, or Oil settings.

Toggle the fields you want synced and tap Apply Selected Settings to All Teams. Useful for the common case of Varsity and JV both bowling the same opponent on the same lanes with the same oil.

Saving the Match

When you're done:

  1. Verify all scores and lineups.
  2. Tap Save - Match Complete (green button).
  3. If you have partial pin tracking (some games incomplete), you'll get a confirmation dialog. You can save anyway — the pin-derived stats will just be missing for those games.

The match is saved locally. If Live Match Scoring is on and the squad is shared, the final snapshot is also pushed to iCloud.

Clearing the Match

The red Clear All Current Match Data button dumps every open workspace. Use it after a successful save, or if you want to start over from scratch. Requires a confirmation.

Historical Edit Mode

If you tap Edit from a match's detail view in History, the Log Match tab opens in a special mode:

  • A blue banner at the top shows Modifying Past Record.
  • The workspace is pre-populated with the historical match data.
  • Every field is editable — scores, lineups, opponent, date, oil pattern.
  • The Save button changes to Update Record.
  • The Clear button becomes Cancel Update.

Changes overwrite the existing match — no duplicate is created.

Editing a match doesn't automatically republish it if it was previously shared. If Live Match Scoring is on and you edit a shared match, the update publishes on save — but co-coaches on other devices only see it when their app refreshes.
